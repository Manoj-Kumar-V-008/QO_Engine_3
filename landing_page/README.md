# Quantum Orbit Engine 3 — Landing Page v5

Multi-color Deep-Space Aurora edition for **Quantum Orbit Engine 3** (`https://3sora.vercel.app/console`).

## What's New in v5
- **Header & Webpage Comets + Roaming Satellites**:
  - Dedicated micro-satellites orbit directly around the floating header navigation dock.
  - Glowing comets (solar gold, cyan, violet, emerald) periodically streak across the header zone and diagonally across random parts of the webpage, alongside roaming micro-satellites with solar wings and dashed orbital wakes.
- **2-Second Idle Cursor → Mini Earth & Revolving Satellites**:
  - Leaving the cursor idle for 2 seconds smoothly morphs the round cursor dot into a spinning mini Earth with glowing oceans, continents, and atmosphere—while 3 tiny winged satellites (cyan, violet, amber) fade in and revolve around it on tilted 3D elliptical orbits.
  - Moving the pointer immediately transitions it back into the responsive orbital crosshair.

## Run Locally or Deploy
```bash
cd quantum-orbit-3-landing-v5
npx serve .
```
Or deploy to Vercel:
```bash
npx vercel --prod
```
